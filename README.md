# Tebak-Daerah

Tebak-Daerah adalah game edukasi tentang kota-kota di Indonesia. Pemain bisa membuat room, masuk ke room dengan kode, atau melihat room yang tersedia. Di dalam room, pemain bermain secara real-time untuk menebak nama kota dari petunjuk atau tampilan yang diberikan.

## Deskripsi Project

Project ini dibuat sebagai game edukasi interaktif dengan konsep multiplayer. Setiap pemain bisa mengisi nickname dan avatar, lalu bergabung ke room sebagai host atau peserta. Sistem room dibuat supaya beberapa pemain bisa bermain dalam satu sesi yang sama.

## Fitur Utama

- Halaman lobby untuk membuat room, join room, dan melihat room yang tersedia
- Input nickname dan avatar pemain
- Room host dan room privat
- Multiplayer real-time
- Sistem permainan tebak nama kota Indonesia
- Penyimpanan data pemain di browser untuk kenyamanan saat pindah halaman

## Teknologi yang Digunakan

- HTML, CSS, dan JavaScript
- Tailwind CSS
- Socket.IO
- Flask
- Node.js backend
- Hono
- Prisma

## Struktur Project

- `tebak-kota/` berisi halaman frontend dan tampilan game
- `backend/` berisi backend API dan logika server game

## Catatan

Project ini masih berfokus pada pengalaman bermain yang sederhana dan interaktif, jadi isi README disesuaikan dengan fitur yang memang sudah ada di dalam kode.
